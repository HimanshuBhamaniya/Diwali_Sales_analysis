# Diwali Sales Analysis

## 📌 Project Overview
This project focuses on analyzing Diwali sales data to uncover actionable insights into customer behavior and purchasing patterns.  
The analysis was performed using **Python (Pandas, NumPy, Matplotlib, Seaborn, OpenDatasets)** in a Jupyter Notebook environment.

---

## 🔎 Process Breakdown

### 1. Data Acquisition & Libraries
- Downloaded the Diwali sales dataset.
- Imported essential libraries: Pandas, NumPy, Matplotlib, Seaborn, OpenDatasets.

### 2. Data Import & Initial Exploration
- Loaded the dataset into Jupyter Notebook.
- Previewed the first 10 rows and used `.info()` to examine structure, data types, and missing values.

### 3. Data Preprocessing
- Dropped unnecessary columns.
- Handled missing values appropriately.
- Used `.describe()` to generate statistical summaries for numeric fields (age, orders, amount).

### 4. Exploratory Data Analysis (EDA)
- **Gender Analysis**: Female buyers showed higher purchasing power.  
- **Age Group Analysis**: 26–35 age group (especially females) were the most active buyers.  
- **Regional Analysis**: Uttar Pradesh, Maharashtra, and Karnataka emerged as top regions for sales.  
- **Marital Status Analysis**: Married women were significant spenders.  
- **Occupation Analysis**: Customers in IT, healthcare, and aviation sectors had higher spending.  
- **Product Category Analysis**: Food, clothing & apparel, and electronics were the most purchased categories.

---

## 💡 Key Insights
- **Target Segment**: Married women aged 26–35 from Uttar Pradesh, Maharashtra, and Karnataka.  
- **High-Spending Occupations**: IT, healthcare, and aviation professionals.  
- **Popular Categories**: Food, clothing & apparel, and electronics gadgets.  

These insights can help businesses **optimize sales strategies during festive seasons** by focusing on the most active and profitable customer segments.
